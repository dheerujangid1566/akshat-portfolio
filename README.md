# Akshat — Portfolio

An animated single-page portfolio for Akshat, a BTech student.

- Plain HTML, CSS and JavaScript — no build step
- Three.js particle galaxy hero that reacts to the cursor and scroll
- Scroll-reveal animations, animated counters, typing effect, card tilt and project filters
- Palette: `#7C5CFF` `#22D3EE` `#F472B6` on `#0B1020`
- Placeholder images from [picsum.photos](https://picsum.photos)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Deployed on Render as a static site with publish directory `./` and no build command.
